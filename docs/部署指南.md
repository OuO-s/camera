# 现场部署指南 — 电脑侧相机服务

目标：在一台新的 Windows 电脑上，把两台 D435 接进来，让 Jetson 上的调试台 `:7010` 能看到相机画面。

> 现场实际用的机器：`192.168.2.200`（有线网段 `192.168.2.x`，与机械臂/主控同网段）。

---

## 一、接线

| 项 | 要求 |
|---|---|
| 接口 | **USB 3.0 蓝色口**（USB2 下深度流会严重降级甚至报错） |
| 数据线 | 必须是 USB3 数据线（很多延长线只有 USB2 线芯） |
| 相机 | 左臂腕 `262322071271`、右臂腕 `262022070108`（序列号印在相机底部） |
| 供电 | 不要接无源 USB Hub；两台一起用建议一台插前面板、一台插后面板 |

---

## 二、装驱动

1. 先做**免安装验机**：双击 `driver\RealSense.Viewer.exe`。
   两台相机会出现在左上角下拉框，能看到彩色 + 深度画面即硬件正常。
   - 右上角显示 `USB 3.2` 才对；显示 `USB 2.1` 说明口或线不对。
2. 正式使用装**官方完整 SDK**：从本仓库 **Releases** 下载
   `RealSense.SDK-WIN10-2.58.4.10922.exe`，右键「以管理员身份运行」，默认选项。
3. 装完**重启电脑**。重启后开始菜单里的 RealSense Viewer 也应能同时看到两台相机。
4. Python 连通性自检（可选）：

```powershell
.\.venv\Scripts\python.exe driver\test_d435.py
```

脚本会列出所有相机（带序列号对照），每台存一张彩图到 `snapshots\`，并打印深度均值。

---

## 三、装 Python 环境

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U pip
.\.venv\Scripts\python.exe -m pip install -r camera-check\requirements.txt
```

现场机器实测版本（2026-10）：Python `3.12.6`、pyrealsense2 `2.58.4`、numpy `2.5.3`、
opencv `5.0.0`、websockets `15.0.1`。

> 如果 `pip install pyrealsense2` 失败，先把第二节的 SDK 装上再试；
> SDK 安装包同时带了 Python 绑定。

---

## 四、起服务

```powershell
.\.venv\Scripts\python.exe camera-check\realsense_server.py
```

正常输出会列出两台相机和监听端口。然后：

1. 本机打开 <http://localhost:8765>，在检查台里选两台相机的序列号，看两路画面。
2. 局域网内用 `http://192.168.2.200:8765` 访问同一页面。

**开机自启**（可选，用任务计划程序）：

```
程序:   D:\...\ .venv\Scripts\python.exe
参数:   camera-check\realsense_server.py
起始于: 仓库根目录
触发器: 登录时 / 开机时
```

---

## 五、防火墙放行

Windows 默认会拦入站。首次运行弹出询问时勾选**专用网络**并允许。
若已误拦，用管理员 PowerShell 放行：

```powershell
New-NetFirewallRule -DisplayName "camera-check 8765" -Direction Inbound -Protocol TCP -LocalPort 8765 -Action Allow
New-NetFirewallRule -DisplayName "camera-check 8766" -Direction Inbound -Protocol TCP -LocalPort 8766 -Action Allow
```

---

## 六、从 Jetson 验证链路

把 `camera-brain/` 两个文件拷到 Jetson，然后：

```bash
python3 -m pip install -r requirements-jetson.txt
python3 jetson_ws_receiver.py --host 192.168.2.200                    # 只收流
python3 jetson_ws_receiver.py --host 192.168.2.200 --display          # 有桌面时显示双路
python3 jetson_ws_receiver.py --host 192.168.2.200 --probe-depth 320 240   # 验深度查询
```

打通后，调试台 `:7010` 的相机区应出现实时画面，右上角健康灯
`相机L` / `相机R` 变绿。

---

## 七、排错

| 现象 | 先查 | 处理 |
|---|---|---|
| 检查台里没有设备 | USB 口/线 | 换 USB3 蓝口，换 USB3 线；重新插拔后点「刷新设备」 |
| 只发现一台 | 掉线那台 | 重新插拔；换口；确认没被别的程序独占 |
| 相机连接失败 | 独占 | 关掉 RealSense Viewer / 其它 `pyrealsense2` 进程（不允许多进程共享） |
| 两路选同一序列号 | — | 页面会阻止；一台一个序列号 |
| 深度全 0 | 距离 | D435 有效深度约 0.3–3m，太近全零；确认不是 USB2 |
| 网页能开、Jetson 收不到流 | 防火墙 | 按第五节放行，并在 Jetson 上 `nc -vz 192.168.2.200 8766` |
| 画面卡顿 | 带宽/分辨率 | 检查是否插在 USB2；避免同时开 Viewer 预览 |

> **重要**：调试台要求相机**只被一个进程读**。排查完记得把 Viewer 关掉，再让
> `camera-check` 起服务。
