## 二、建仓库 & 推代码

```powershell
# 1) 本地初始化
cd OuO-s-camera
git init -b main
git config user.name  "OuO-s"
git config user.email "OuO-s@users.noreply.github.com"
git add -A
git commit -m "初始备份：电脑侧双路 D435 相机服务 + 驱动"

# 2) 关联远端并推送（远端仓库要先在 GitHub 上建好，见下）
git remote add origin https://github.com/OuO-s/camera.git
git push -u origin main
```

远端仓库两种建法：

- **网页建**：GitHub → New repository → 名字 `camera` → **不要**勾 Add README（否则要先 pull）。
- **API 建**（本仓库就是用这个建的）：

```powershell
$tok = (("protocol=https`nhost=github.com`n`n" | git credential fill) -split "`n" |
        Select-String '^password=').ToString().Split('=')[1]
$H = @{ Authorization = "Bearer $tok"; Accept = "application/vnd.github+json"; "User-Agent" = "setup" }
Invoke-RestMethod -Uri "https://api.github.com/user/repos" -Headers $H -Method Post -ContentType "application/json" `
  -Body '{"name":"camera","private":false,"description":"双路 USB 相机采集端（电脑侧）"}'
```

> 令牌从 Windows 凭据管理器里取（`git credential fill`），**不要**写进任何文件、
> 不要提交、不要贴到聊天里。要撤销就清掉 `git:https://github.com` 这条凭据。

## 三、驱动为什么走 Release

| 文件 | 大小 | 处理方式 |
|---|---|---|
| `RealSense.Viewer.exe` | 18.9 MB | **进仓库** `driver/`，免安装验机用 |
| `test_d435.py`、`README_先看我.md` | <10 KB | **进仓库** `driver/` |
| `RealSense.SDK-WIN10-2.58.4.10922.exe` | **116 MB** | **发 Release 附件** |
| `D435_SDK_v2.58.4_Windows.zip`（原始整包） | 123.7 MB | 同上，可一并作为附件 |

原因：**GitHub 单个文件硬上限 100MB**，直推会被拒（`remote: error: File ... is 123.70 MB;
this exceeds GitHub's file size limit of 100.00 MB`）。Release 附件单文件可到 2GB，
而且不占仓库体积、克隆不会拖慢。

## 四、发 Release（上传驱动）

用仓库里的脚本：

```powershell
# 不传参 → 自动找桌面/下载目录里的 D435_SDK_v2.58.4_Windows.zip
pwsh -File tools\publish_release.ps1

# 或指定文件与标签
pwsh -File tools\publish_release.ps1 -Tag v1.0-driver -Files "C:\path\D435_SDK_v2.58.4_Windows.zip"
```

脚本会：读令牌 → 建/取 Release（标签 `v1.0-driver`）→ 逐个上传附件 → 打印附件下载地址。

上传后把地址填进 `README.md` 和 `driver/README_先看我.md`，别人就知道去哪下。
